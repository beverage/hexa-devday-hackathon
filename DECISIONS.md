| D-009 | 2026-10-23 | **The response config (level × register cell) is decided ahead of time, never by a call in front of the reply.** The agent drafts in **English**, level-neutral, never pre-simplified; Levelang does all calibration (a French draft works only via auto-detect, since `source_language: fra` is refused: a Saturday experiment, not the default). The cell comes from state the background judge keeps. On the reply path a pure-code gate (~1 ms) reads the realtime text: (1) comprehension failure ("je ne comprends pas", "pardon ?", "plus lentement", "répétez", English) → drop one level and **re-say the previous reply from the neighbour below, already rendered**: no draft, no render; (2) explicit request ("parlez plus simplement", "on peut se tutoyer") → apply now; (3) otherwise the current estimate, the common case at zero cost. The cell is picked when the draft finishes, and a judge result not in by then applies next turn. Render the chosen cell first, neighbours in the background. Judge: skip turns under ~5 words with no failure phrase ("can't tell"); structured output, `no_change` first; lower at once (via the gate), raise only on floor evidence in 2 of the last 3 turns; register by policy (*vous* by default, *tu* only if asked or persistent), from batch text since realtime rewrites *tu*. The console swaps each realtime caption for the batch text, and history entries become batch text. | The draft doesn't depend on the cell, so the decision has until the draft is done; most turns change nothing, so that path must cost nothing; comprehension-failure phrases are what realtime transcribes reliably (2/2 every run). Measured 10-23: Levelang render EN→FR 1.35–1.67 s per cell on `gemini-3.1-flash-lite`, three cells in ~2.1 s in parallel; realtime commit ~2 s after the caller stops. Draft and judge latency unmeasured (Saturday, IDEA § 2 test 4). Rejected: a "calibration hint" from the draft call (couples agent and detector, so the detector can't be evaluated alone). |
